# Linked Lists
## Description:
A project that implements a basic [Linked List](https://en.wikipedia.org/wiki/Linked_list) data structure in JavaScript along with common operations. Implemented append(value), prepend(value), size(), head(), tail(), at(value), pop(), contains(value), findIndex(), toString().

## Reflection:
Not the most difficult project, but good practice with Test Drive Development(TDD) and helped me review Linked Lists and common operations of linked lists along with their benefits/drawbacks.
